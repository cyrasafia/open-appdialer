# 功能范围

> 本文是 v1 的范围边界，开发以本文为准；变更需先改这里。最后更新：2026-11-14。

## 定位

内置 T9 九宫格键盘的极简 Android 应用搜索启动器：打开即搜，输入几位数字，一键启动应用。

## 范围内（v1 必做）

### 输入：T9 九宫格键盘（唯一输入方式）

- 只有九宫格键盘，没有全键盘，全程不唤起系统输入法（硬性要求）
- 3×3 布局：`2` 键兼含 `1`，`9` 键兼含 `0` 与特殊字符，其余键 = 字母 + 数字本身；左上键短按清空全部输入、长按进设置
- 快速连打不丢字符：按下后手指移出按钮再抬起，数字仍上屏

### 窗口形态

- 主界面为浮窗（浮层面板，无遮罩），非全屏
- 系统返回键、点击浮窗外：直接关闭，不清空输入
- 通知唤起：常驻低优先级通知，点击拉起浮窗（不走桌面启动转场）；仅通知权限一项运行时权限，可拒绝
- dock 直达：NoDisplay 跳板 + overlay 面板 + FGS 常驻（需"显示在其他应用上层"授权，见 spec F10）

### 搜索：只搜应用

- 数据源为设备上可启动的应用列表，实时响应输入
- 中文：全拼、首字母、多音字、混合匹配（微信 → `934946` / `99`）
- 英文/数字：词首与子串模糊匹配
- 排序：匹配度优先，使用频率为次
- 联想结果分页展示：每屏 3 个、最多 2 屏、横划切换，超过 6 个提示继续输入
- 无输入时：新安装应用优先（安装 ≤ 2 小时），其余按最近使用时间降序；点击清空后候选区显示空白，不恢复默认列表
- 应用列表随安装/卸载/更新增量刷新，图标与元数据磁盘缓存（避免冷启动慢）

### 启动

- 点击结果即启动应用
- 长按候选弹出菜单：添加桌面快捷方式（Android 8+）、查看详情、卸载
- 被系统冻结（cached app freezer）的应用也能正常启动

### 主题

- 深色 / 浅色两套主题，跟随系统 + 手动切换

### 语言

- 界面与搜索明确支持中文、英文；其他语言后续视情况

### 平台与目标

- 仅 Android；target SDK 36+，min SDK 23 左右，跟进后续 Android 版本
- 无网络权限，APK 体积目标 < 1 MB 级别

## 范围外（明确不做）

- **全键盘 / 文本输入**：T9 是唯一输入方式
- **联系人**：不搜联系人，不做拨号、短信等任何联系人相关功能
- **Widget**：不做任何桌面小部件
- **图标包**：不做图标包支持
- **快速启动面板**：不做原版通知栏常用应用面板之类的快速启动面板
- **扩展搜索**：不做计算器、单位换算、web 搜索、文件搜索等
- **其他平台**：不做 iOS / 桌面端
